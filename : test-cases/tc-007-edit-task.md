# TC-007. Редактирование текста задачи

**Требование:** REQ-04
**Тип:** Позитивный
**Приоритет:** Высокий

## Предусловия
В списке есть хотя бы одна задача.

## Шаги
1. Нажать на кнопку «Редактировать» рядом с задачей.
2. Изменить текст задачи.
3. Нажать «Сохранить» (или Enter).

## Ожидаемый результат
Текст задачи успешно изменён и отображается в списке в новом виде.
