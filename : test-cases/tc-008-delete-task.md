# TC-008. Удаление задачи

**Требование:** REQ-05
**Тип:** Позитивный
**Приоритет:** Высокий

## Предусловия
В списке есть хотя бы одна задача.

## Шаги
1. Нажать на кнопку «Удалить» (корзина или крестик) рядом с задачей.
2. Подтвердить удаление (если появится диалоговое окно).

## Ожидаемый результат
Задача исчезает из списка. Счётчик задач обновляется.
