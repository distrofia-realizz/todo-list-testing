# TC-011. Очистка выполненных задач

**Требование:** REQ-07
**Тип:** Функциональный
**Приоритет:** Средний

## Предусловия
В списке есть несколько выполненных задач.

## Шаги
1. Нажать на кнопку «Очистить выполненные».

## Ожидаемый результат
Все выполненные задачи удаляются из списка. Активные задачи остаются нетронутыми.
