# TC-015. Отмена редактирования по Escape

**Требование:** REQ-04
**Тип:** Негативный
**Приоритет:** Низкий

## Предусловия
В списке есть задача.

## Шаги
1. Нажать «Редактировать» рядом с задачей.
2. Изменить текст.
3. Нажать клавишу Escape (Esc) на клавиатуре.

## Ожидаемый результат
Редактирование отменяется. Текст задачи остаётся прежним (изменения не сохраняются).
