# TC-005. Добавление задачи длиной 201 символ

**Требование:** REQ-02
**Тип:** Граничный
**Приоритет:** Средний

## Предусловия
Приложение открыто, список задач пуст.

## Шаги
1. Ввести текст, состоящий из 201 символа.
2. Нажать кнопку «Добавить».

## Ожидаемый результат
Задача не добавляется. Поле ввода подсвечивается красным или появляется сообщение о превышении длины.
