# TC-014. Адаптивность 320px

**Требование:** REQ-10
**Тип:** UI
**Приоритет:** Средний

## Предусловия
Открыт браузер.

## Шаги
1. Открыть инструменты разработчика (F12).
2. Включить режим адаптивного дизайна (Toggle device toolbar).
3. Установить ширину экрана 320px.

## Ожидаемый результат
Интерфейс приложения корректно адаптируется. Нет горизонтальной прокрутки, элементы не наезжают друг на друга.
