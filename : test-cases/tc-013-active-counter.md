# TC-013. Счётчик активных задач

**Требование:** REQ-09
**Тип:** UI
**Приоритет:** Низкий

## Предусловия
В списке есть активные задачи.

## Шаги
1. Посмотреть на счётчик (обычно внизу списка).
2. Добавить новую активную задачу.
3. Отметить одну задачу как выполненную.

## Ожидаемый результат
Счётчик корректно отображает количество именно активных задач и меняется при их добавлении/выполнении.
