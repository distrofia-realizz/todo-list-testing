# TC-006. Отметка задачи как выполненной

**Требование:** REQ-03
**Тип:** Позитивный
**Приоритет:** Высокий

## Предусловия
В списке есть хотя бы одна активная задача.

## Шаги
1. Найти активную задачу в списке.
2. Нажать на чекбокс (или кнопку отметки) рядом с задачей.

## Ожидаемый результат
Задача визуально меняет статус на «Выполнена» (например, зачеркивается текст). Счётчик активных задач уменьшается на 1.
